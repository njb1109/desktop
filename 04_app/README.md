# Beam Designer

Beam Designer analyzes simply supported beams and cantilevers with point and
uniform loads. It displays shear, moment, and deflection diagrams, checks
bending and deflection limits, and can save/open designs, export CSV results,
and create a PDF calculation sheet.

## Install

Install the required packages from the project root:

    python -m pip install -r 04_app/requirements.txt

This installs NumPy and Matplotlib. Tkinter is included with most Python
installations.

## Start

From the project root, run:

    python.app.py
