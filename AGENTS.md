# Project layout

This is a single-file web app. Keep `AGENTS.md`, `spec.md`, `prompts.md`, and the GitHub Pages entry point `index.html` at the project root.

- `00_planning/`: planning notes and sketches.
- `01_data/`: project data files.
- `02_validation/`: hand calculations and test cases.
- `03_output/`: screenshots and exported results.

Save every new file in the appropriate root location or numbered folder based on its purpose. Do not add project materials at the root unless they are one of the designated root files.
